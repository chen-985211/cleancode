# 项目待办清单

Todo 独立管理一个项目的清单，通过 Project 提供的稳定项目 ID 定位。分支或工作区切换不改变清单身份。条目 ID、内容、备注、引用链接、图片 ID 和完成状态由清单维护。项目 Issues、工作区运行状态与 AI 会话各自保有原有归属。

同一条目从待办、进行中、已完成依次循环。首次进入已完成时记录完成时间，编辑已完成的内容保留该时间，重新打开条目时清除它。清单收到没有文字、备注、链接和截图的条目时移除该条目。截图或链接可以单独构成条目。

桌面主进程在应用状态根的 `todos/<项目 ID 的 SHA-256>/` 保存清单。版本 1 的 `list.json` 保存条目与附件引用，图片以独立的 `<图片 ID>.image` 保存。每个项目的读写按顺序执行，先写完新增附件，再原子替换清单，最后回收失去引用的附件。读取清单时回收未完成提交留下的临时文件和无引用图片。未知版本或损坏的数据会返回错误，正常退出会等待已受理的写入。
